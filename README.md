# KNN, классификация и регрессия


## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Выполнение без интерфейса:

```bash
.venv/bin/python scripts/execute_notebook.py
```

Результаты записываются в ноутбук и в `results/`: таблицы CV, параметры поиска, тестовые метрики, прогнозы, индексы разбиений и контрольные суммы данных.
