# Исследования моделей классификации и регрессии

- `research-1.ipynb` — лабораторная №1: метод k ближайших соседей (KNN).
- `research-2.ipynb` — лабораторная №2: логистическая и линейная регрессия, включая Ridge.
- `research-3.ipynb` — лабораторная №3: решающие деревья для классификации и регрессии, собственный CART.
- `research-4.ipynb` — лабораторная №4: случайный лес для обеих задач, собственные CART и Random Forest, OOB-диагностика.
- `research-5.ipynb` — лабораторная №5: градиентный бустинг для обеих задач, собственные регрессионные деревья и бустинг, исследование потерь по итерациям.

Каждый ноутбук выполняется самостоятельно и содержит постановку экспериментов, пояснения к ячейкам
, модели sklearn, собственные реализации, таблицы качества и выводы.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Откройте нужный ноутбук, выберите созданное окружение. Данные уже находятся в `data/`.

## Результаты

Сводные таблицы, графики и вычисляемые выводы по всем пяти работам доступны в [results.ipynb](results.ipynb). Он читает готовые CSV из `results/` без повторного обучения моделей.

Сравнение составлено по сохранённым таблицам `results/research-1/`–`results/research-5/` и выводам ячеек ноутбуков. «Исходный» означает `baseline`, «улучшенный» — конфигурацию, выбранную внутри соответствующей работы по кросс-валидации. Основные таблицы ниже относятся к sklearn; собственные реализации NumPy сравниваются отдельно. Значения округлены, исходная точность сохранена в CSV.

### Условия сравнения

Во всех пяти работах используются одинаковые CSV, очистка, целевые переменные и разбиения с `random_state=42`:

- Классификация Steam: 6400 обучающих и 1600 тестовых строк, доля `hit=1` — 20%. Разбиение стратифицировано. Основная метрика — **Average Precision (AP)**; F1, precision и recall считаются для класса 1 с порогом вероятности >0.5.
- Регрессия продаж: 13272 обучающих и 3326 тестовых строк. Разные платформенные версии одной игры разделяются по группе нормализованного названия, чтобы не пересекать train/test. Цель `global_sales` — продажи в **миллионах копий**. Основная метрика — **MAE**, дополнительные — RMSE и R².
- Гипотезы и параметры выбираются на 3-fold CV внутри train; для продаж CV также разделена по группам. Заполнение пропусков и кодирование обучаются внутри Pipeline. Тест используется после фиксации выбора, без последующей настройки.

Поэтому результаты можно сопоставлять на одном тесте. При этом каждая работа исследует собственную ограниченную сетку и подготовку признаков: таблицы показывают качество конкретных проверенных конфигураций, а не предел возможностей алгоритмов.

### Классификация: сравнение sklearn

Чем больше AP, F1 и ROC AUC, тем лучше. Dummy, предсказывающий постоянную вероятность, имеет AP=0.2000 и ROC AUC=0.5000. Его accuracy=0.8000 при F1=0: высокая доля правильных ответов получается за счёт выбора большинства, поэтому accuracy не используется как основная метрика.

| Алгоритм | AP исходный | AP улучшенный ↑ | F1 улучшенный ↑ | ROC AUC улучшенный ↑ |
| --- | --- | --- | --- | --- |
| 1. KNN | 0.5132 | 0.6680 | 0.4990 | 0.8775 |
| 2. Логистическая регрессия | 0.6929 | 0.7208 | 0.6328 | 0.9030 |
| 3. Решающее дерево | 0.3370 | 0.6697 | 0.6102 | 0.8852 |
| 4. Случайный лес | 0.6722 | 0.7176 | 0.6321 | 0.9016 |
| 5. Градиентный бустинг | 0.7042 | 0.7130 | 0.6104 | 0.9005 |

На этом тесте среди улучшенных моделей sklearn лучшая AP у **логистической регрессии: 0.7208**, затем идут случайный лес (0.7176) и градиентный бустинг (0.7130). Логистическая регрессия также имеет наибольшую F1 (0.6328), но отрыв от леса (0.6321) мал; один тест не подтверждает статистическую значимость такого различия. Простая модель оказалась конкурентоспособной с ансамблями в исследованных настройках.

Наибольший прирост AP относительно исходной модели получило решающее дерево для классификации: **0.3370 → 0.6697**. У исходного дерева train AP=1, глубина 23, а тестовая AP гораздо ниже — выраженное переобучение. Ограничение глубины и размера листа вместе с проверкой весов классов заметно улучшило результат. Для KNN существенны подготовка и подбор соседей; в бустинге выигрыш относительно уже сильного бейзлайна меньше.

Улучшение основной метрики не означает улучшения всех остальных. Например, у логистической регрессии recall вырос с 0.4531 до 0.8375, а precision снизилась с 0.7632 до 0.5085 после изменения подготовки и регуляризации с весами классов. Это объясняет рост F1 при снижении accuracy. Полные показатели всех моделей находятся в `test_metrics.csv`.

### Регрессия: сравнение sklearn

MAE и RMSE приведены в **миллионах копий**, меньше — лучше; R² больше — лучше. Dummy прогнозирует медиану train и даёт MAE=0.456185, RMSE=1.6167. Его отрицательный R² допустим: R² использует ориентир со средним, а медиана оптимальна для абсолютной ошибки.

| Алгоритм | MAE исходный | MAE улучшенный ↓ | RMSE исходный | RMSE улучшенный ↓ | R² улучшенный ↑ |
| --- | --- | --- | --- | --- | --- |
| 1. KNN | 0.8314 | 0.4565 | 1.7960 | 1.5109 | 0.0819 |
| 2. Линейная регрессия / Ridge | 0.5348 | 0.4468 | 1.4714 | 1.4993 | 0.0958 |
| 3. Решающее дерево | 0.5333 | 0.4450 | 1.5216 | 1.5048 | 0.0893 |
| 4. Случайный лес | 0.4970 | 0.4383 | 1.4456 | 1.4957 | 0.1002 |
| 5. Градиентный бустинг | 0.5337 | 0.4486 | 1.4908 | 1.5111 | 0.0816 |

Среди улучшенных sklearn-моделей лучшая MAE у **случайного леса: 0.4383 млн копий**, примерно на **3.93%** ниже медианного Dummy. Далее идут дерево (0.4450), линейная модель с Ridge (0.4468), бустинг (0.4486) и KNN (0.4565). Для каждого из пяти семейств CV выбрала вариант с логарифмированием цели продаж; обратное преобразование выполняется до расчёта тестовых метрик.

Улучшенный KNN почти сравнялся с Dummy, но немного уступил ему по MAE: **0.456519 против 0.456185**. Большое улучшение относительно собственного слабого бейзлайна 0.8314 ещё не означает преимущества над простым ориентиром. Остальные четыре улучшенные модели sklearn превзошли Dummy по MAE на этом тесте.

Для линейных моделей, леса и бустинга MAE снизилась, но RMSE выросла. Логарифмирование уменьшает влияние редких блокбастеров при обучении и меняет центр прогноза; типичная абсолютная ошибка может уменьшиться при увеличении отдельных крупных промахов. Среди исходных sklearn-моделей лес имеет RMSE=1.4456 и R²=0.1594 — лучше его выбранного по MAE варианта. Выбор по MAE не равнозначен выбору по RMSE.

У улучшенных моделей R² находится примерно в диапазоне **0.08–0.10**: качество прогноза продаж остаётся ограниченным. В тестовой выборке медиана продаж — 0.17 млн, максимум — 33 млн, поэтому RMSE существенно выше MAE. Во второй работе исходная линейная модель дала 408 отрицательных прогнозов, улучшенная — 68. Отрицательные продажи физически невозможны, хотя допустимы для использованных моделей без ограничений; эти прогнозы не обрезались при оценке.

### Что показала кросс-валидация

Ниже средняя оценка ± стандартное отклонение по трём fold у выбранной конфигурации каждой работы. Для удобства MAE показана положительной; в файле CV хранится её отрицательное значение.

| Работа | AP выбранной модели на CV ↑ | MAE выбранной модели на CV ↓ |
| --- | --- | --- |
| 1 | 0.6629 ± 0.0081 | 0.4689 ± 0.0165 |
| 2 | 0.7091 ± 0.0160 | 0.4523 ± 0.0148 |
| 3 | 0.6450 ± 0.0228 | 0.4569 ± 0.0130 |
| 4 | 0.6802 ± 0.0269 | 0.4464 ± 0.0149 |
| 5 | 0.6920 ± 0.0212 | 0.4552 ± 0.0148 |

По CV классификации лидирует логистическая регрессия, а по CV регрессии — случайный лес; эти лидеры сохранились и среди улучшенных sklearn-моделей на тесте. Стандартное отклонение по fold не является доверительным интервалом. Последовательный выбор гипотез и параметров на тех же fold делает итоговую CV-оценку оптимистичной.

Не все гипотезы подтвердились: пакет преобразований H1 с дополнительными признаками ухудшил среднюю CV-оценку регрессии во второй, третьей и четвёртой работах; стохастическая подвыборка в пятой работе помогла классификации, но ухудшила регрессию. Поэтому добавление признаков, усложнение модели или увеличение числа деревьев оценивались экспериментально, а не принимались как гарантированное улучшение.

### Сравнение собственных реализаций NumPy со sklearn

В таблице приведены исходные и улучшенные метрики собственных моделей. Δ — разность **NumPy improved − sklearn improved**: положительная ΔAP означает более высокую AP, отрицательная ΔMAE — меньшую ошибку продаж. Все MAE измеряются в миллионах копий. Нулевые Δ означают совпадение на уровне указанного округления.

| Алгоритм NumPy | AP: исходный → улучшенный | MAE: исходный → улучшенный | ΔAP к sklearn | ΔMAE к sklearn |
| --- | --- | --- | --- | --- |
| 1. KNN | 0.5132 → 0.6680 | 0.8806 → 0.4789 | 0.000000 | +0.022416 |
| 2. Логистическая / линейная регрессия | 0.6929 → 0.7208 | 0.5348 → 0.4468 | 0.000000 | 0.000000 |
| 3. Решающее дерево | 0.3527 → 0.6698 | 0.5289 → 0.4450 | +0.000004 | 0.000000 |
| 4. Случайный лес | 0.6577 → 0.7290 | 0.4746 → 0.4373 | +0.011450 | -0.000994 |
| 5. Градиентный бустинг | 0.7042 → 0.7136 | 0.5337 → 0.4486 | +0.000642 | 0.000000 |

- Логистическая и линейная регрессии практически совпали со sklearn по прогнозам: максимальное отличие вероятностей около 4.4·10⁻⁷, числовых прогнозов — порядка 10⁻¹³ и меньше. Это согласуется с одинаковыми целевыми функциями и разными численными методами решения.
- У KNN классификация совпала по метрикам, а регрессия различается из-за выбора соседей при равных расстояниях. В диагностике у всех 748 различающихся исходных и 2515 улучшенных прогнозов совпали упорядоченные расстояния до выбранных соседей в заданном допуске. Собственная улучшенная регрессия KNN с MAE=0.4789 также уступает Dummy.
- У CART возможны разные структуры при одинаково выгодных разбиениях и разных численных допусках. После ограничения сложности результаты улучшенных моделей практически совпали; у исходных деревьев расхождения заметнее.
- У леса отличаются генераторы случайных выборок и правила поиска разбиений. Среди улучшенных NumPy-моделей лес показал лучшие AP=0.7290 и MAE=0.4373. Один запуск не доказывает общего превосходства собственной реализации над sklearn. OOB в четвёртой работе используется как дополнительная диагностика; покрытие улучшенного классификатора около 99.86–99.89%, строки без OOB-прогноза исключены. Для продаж OOB не заменяет групповую CV.
- В бустинге исходные прогнозы практически совпали со sklearn, как и улучшенная регрессия. В улучшенной классификации используется стохастическая подвыборка строк, поэтому при разных генераторах NumPy и sklearn получены немного разные результаты: AP=0.7136 и 0.7130 соответственно.

Корректность собственных алгоритмов дополнительно проверяется в ноутбуках на контролируемых примерах. Одного совпадения округлённых метрик недостаточно для доказательства корректности реализации.

### Общие итоги

Для классификации среди проверенных sklearn-конфигураций наиболее удачна логистическая регрессия; среди собственных реализаций — случайный лес. Для регрессии по выбранной основной метрике MAE лидирует случайный лес в обеих реализациях. Усложнение алгоритма само по себе не обеспечило лучшего результата: бустинг с исследованными настройками не превзошёл всех конкурентов.

Все выбранные улучшения повысили основную тестовую метрику относительно соответствующих исходных моделей. При этом KNN в регрессии не обошёл медианный ориентир, а часть улучшений MAE сопровождалась ухудшением RMSE. Это подчёркивает необходимость сравнивать несколько метрик и Dummy, а не только исходную и улучшенную версии одного алгоритма.

Выводы относятся к данным, разбиениям и ограниченным сеткам этих пяти экспериментов. Один общий holdout не доказывает статистическую значимость различий между алгоритмами. Steam-набор синтетический, что указано автором в `data/steam/README.md`; исторические продажи отобраны по наличию продаж и имеют разные сроки накопления. Для практического применения нужны реальные дорелизные признаки, единый горизонт продаж и проверка на будущих релизах.

### Файлы в `results/`

Каждая работа при выполнении перезаписывает **только две таблицы в своей папке**. Результаты других работ не затрагиваются. Обученные модели, массивы прогнозов и полные результаты поиска находятся в памяти ядра и не сохраняются в этих CSV. Графики, напечатанные таблицы и диагностические сообщения сохраняются в выводах соответствующего ноутбука.

| Папка | Работа |
| --- | --- |
| [`results/research-1/`](results/research-1/) | KNN |
| [`results/research-2/`](results/research-2/) | Логистическая и линейная регрессия, Ridge |
| [`results/research-3/`](results/research-3/) | Решающее дерево |
| [`results/research-4/`](results/research-4/) | Случайный лес |
| [`results/research-5/`](results/research-5/) | Градиентный бустинг |

**`cv_experiments.csv` — проверка гипотез внутри обучающей выборки.** Одна строка содержит сводную оценку эксперимента; для этапа с подбором параметров — оценку лучшей конфигурации этого этапа, а не все комбинации сетки и не отдельные fold.

| Столбец | Содержание |
| --- | --- |
| `task` | `c` — классификация, `r` — регрессия. |
| `experiment` | Название этапа: H0 — исходный бейзлайн; H1 и далее — гипотезы. Конкретное содержание H2–H4 зависит от работы и описано в ноутбуке. |
| `selection_score` в работе №1, `score` в работах №2–5 | Средняя CV-оценка: AP для классификации, −MAE для регрессии. В обоих случаях больше — лучше; отрицательная оценка регрессии не означает отрицательную ошибку. |
| `std` | Стандартное отклонение оценки по трём fold. |

**`test_metrics.csv` — итоговая оценка на отложенном тесте.** В каждой работе 10 строк: по пять вариантов для классификации и регрессии. `model` принимает значения `Dummy`, `sklearn baseline`, `sklearn improved`, `numpy baseline`, `numpy improved`. `baseline` — исходная модель, `improved` — модель с улучшениями, выбранными по CV; в NumPy переносятся выбранные для sklearn техники и настройки.

| Столбец | Содержание |
| --- | --- |
| `task`, `model` | Задача и вариант модели. |
| `AP`, `ROC_AUC` | Качество ранжирования положительного класса по вероятностям. |
| `F1`, `Precision`, `Recall` | F1, точность и полнота класса 1 при пороге >0.5. |
| `Balanced_accuracy`, `Accuracy` | Средняя полнота по классам и общая доля правильных ответов. |
| `MAE`, `RMSE` | Абсолютная и среднеквадратичная ошибки продаж в миллионах копий. |
| `R2` | Коэффициент детерминации; может быть отрицательным. |
| `predict_seconds` | Измеренное время предсказания и вычисления метрик на тесте, без обучения и CV. Зависит от оборудования и запуска; это не отдельный строгий бенчмарк скорости. |
| `negative_predictions` | Число отрицательных прогнозов продаж; столбец присутствует в работах №2 и №5. |

Пустые значения, читаемые pandas как `NaN`, означают неприменимость метрики к задаче: например, AP не вычисляется для регрессии, а MAE — для классификации. Графики, результаты тестов реализаций, OOB и диагностика соседей отображаются в ноутбуках и не создают дополнительных файлов в `results/`.
